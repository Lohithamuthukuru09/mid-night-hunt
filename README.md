# The Midnight Tide 🌊

An interactive, story-driven birthday experience — a midnight seaside treasure hunt that reveals a hidden name one glowing letter at a time, ending in a sunrise finale.

![Tech](https://img.shields.io/badge/HTML-CSS-JS-blue)

## ✨ What It Is

"The Midnight Tide" is a single-page web experience built as a birthday surprise. The story: a message in a bottle washes ashore, sending the visitor on a hunt across a midnight seascape. Seven glowing letters are hidden in interactive scenes — shells, plankton, a compass, oysters, a lighthouse, a clam, and a bonfire. Each scene reveals one letter, slowly assembling the name **MAMATHA** before the tide speaks it aloud and the sun rises. 🌅

## 🎮 Features

- **10 Story Pages** — each page is a themed scene with its own animation
- **7 Interactive Mini-Games**
  - 🐚 Pick the glowing shell
  - ✨ Catch the golden plankton light
  - 🧭 Spin the sailor's compass
  - 🦪 Open the oysters
  - 🔦 Tap the lighthouse lamp 3 times
  - 🐚 Wake the sleeping clam
  - 🔥 Build the bonfire
- **Progress Tracker** — circular slots fill up as each letter is found
- **Pop-up Letter Animations** — letters burst onto the screen when found
- **Name Assembly Scene** — chips flip over one by one to reveal the name
- **Sunrise Finale** — animated sun, confetti rain, and a personal wish
- **Fully Self-Contained** — one HTML file, no external dependencies
